# Sottovoce v1.0-beta

App somatica per prendersi cura del sistema nervoso e fare le cose.

## Cosa è Sottovoce?

Sottovoce è uno spazio digitale per accompagnare il tuo sistema nervoso — attraverso la voce, il corpo, i compiti che contano.

## Features v1.0

- ✓ Check-in emotivo 5 stati
- ✓ Audio guide somatiche (voce di Nadia)
- ✓ Task manager per tre aree: Cose per me, Cose per chi amo, Cose per la casa
- ✓ Accumulo check-in (memoria grezza)

## Come usare

1. Apri `index.html` nel browser
2. Clicca uno dei 5 pulsanti per il check-in
3. Aggiungi i tuoi compiti
4. Tutto viene salvato automaticamente nel browser
