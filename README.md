# Sottovoce

**Il task manager per la vita quotidiana. Con il sistema nervoso dalla tua parte.**

## Cosa è Sottovoce?

Sottovoce è uno spazio digitale per accompagnare il tuo sistema nervoso — attraverso la voce, il corpo, i compiti che contano.

Per persone con sistema nervoso sensibile, altamente stimolabili, o che semplicemente vogliono prendersi cura di sé mentre fanno le cose.

## Come funziona

1. **Check-in emotivo** — Racconti come stai (5 stati)
2. **Guida somatica** — Ascolti la voce di Nadia che ti accompagna nel corpo
3. **Task manager** — Aggiungi compiti nelle tre aree: Per me, Per chi amo, Per la casa
4. **Fai le cose** — Piano piano, con il sistema nervoso dalla tua parte
